# Автосервис CARTA

Клиент-серверное приложение для учёта смен автосервиса CARTA.

## Структура

- `android/` — Android-приложение (Kotlin + XML)
- `server/` — backend (FastAPI + WebSocket + SQLite)

## Связь в реальном времени

Используется **WebSocket** (`ws://` / **`wss://`**). Это даёт моментальные обновления смены на всех подключённых клиентах без опроса. Для продакшена включите TLS (`CARTA_USE_TLS=1` + сертификаты) — клиент поддерживает `wss://`.

## Сервер

### Быстрый старт

```bash
cd server
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

База данных: файл `server/carta.db` (SQLite).  
Сервер: `http://0.0.0.0:8443`, WebSocket: `ws://<host>:8443/ws`, health: `/health`.

### Docker (локально / VPS)

Из **корня** репозитория:

```bash
docker compose up -d --build
```

Приложение: `http://127.0.0.1:8443/`, WebSocket: `ws://127.0.0.1:8443/ws`.  
Данные SQLite — volume `carta_data`.

Деплой на VPS с Nginx и HTTPS: см. [deploy/DEPLOY.md](deploy/DEPLOY.md).

Старый вариант только из `server/` больше не рекомендуется (веб-клиент не попадёт в образ).

### Учётные записи

Дефолтных `admin` / `user` / `accountant` **больше нет**.

При первом запуске создаётся один суперпользователь из переменных окружения:

```bash
cp .env.example .env
# отредактируйте ADMIN_LOGIN и ADMIN_PASSWORD
```

Остальных пользователей (сотрудник, бухгалтер) создаёте в **Администрирование → Пользователи**.

Денежное хранилище по умолчанию: **Касса, наличные**.  
Виды расходов загружены из файла «Совокупные расходы» (+ отдельный вид **Инкассация**).

### Логика смены

Смена дня D открывается в **05:00** и закрывается в **05:00** следующего дня (таймзона `Europe/Moscow`). Все действия пишутся в `action_logs` (отчёт LOGS).

## Веб-клиент (ПК)

После запуска сервера откройте в браузере:

```
http://127.0.0.1:8443/
```

Веб-интерфейс повторяет мобильное приложение (те же роли, экраны и WebSocket API).  
WebSocket подключается к тому же хосту, что открыт в браузере (`ws://…/ws` / `wss://…/ws`).

## Android

1. Откройте папку `android/` в Android Studio (Ladybug / Hedgehog+).
2. Дождитесь Gradle Sync.
3. В эмуляторе адрес сервера по умолчанию: `ws://10.0.2.2:8443/ws` (хост-машина).
4. На реальном устройстве укажите в **Настройки** IP компьютера, например `ws://192.168.1.10:8443/ws`.
5. Для TLS: `wss://your.domain/ws`.

### Экраны

- Вход → Главное меню (кнопки зависят от роли)
- Смена / Касса / Посещаемость / Денежные операции
- Архив смен, Настройки, Администрирование, Отчёты (БАЛАНС / ОДДС / ОПиУ / РАСХОДЫ / ПОСЕЩАЕМОСТЬ / LOGS → Excel + «Поделиться»)

Индикатор связи (зелёный/красный круг) — во всех activity.  
Переходы между экранами: fade + лёгкий slide (не «вылет» из кнопки).
